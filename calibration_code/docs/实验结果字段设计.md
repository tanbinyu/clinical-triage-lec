# 第二步，原始数据集划分
这里需要注意，在每次划分（epoch）中，以数据集为单位划分，也即每个数据集在calib和test均占50%，<font style="color:#DF2A3F;">严禁</font>calib里面是一个数据集，test里面又是另外一个数据集，所以可以参考{dataset}_phase_2.json去得到：

<font style="background-color:#FBDE28;">splits_phase_1.json</font>

```json
{
    "splits": [
        {
            "epoch": 0,
            "calib": ["sample_001", "sample_003", "sample_007"],
            "test":  ["sample_002", "sample_004", "sample_005"]
        },
        {
            "epoch": 1,
            "calib": ["sample_002", "sample_005", "sample_007"],
            "test":  ["sample_001", "sample_003", "sample_004"]
        }
    ]
}
```

# 第四步，第二阶段数据集划分
## BranchA（最主要的Branch）
根据splits.json（取splits）、phase_1.json（取uncertainty）、lec_phase_1.json（取t_hat），选取u₁ ≤ t_hat的样本，也即：

第一阶段校准集 中 u₁ ≤ t_hat 的样本 → Branch A 校准集

第一阶段测试集 中 u₁ ≤ t_hat 的样本 → Branch A 测试集
